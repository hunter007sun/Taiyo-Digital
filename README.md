# NEXORA DIGITAL

A responsive digital agency website built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive desktop and mobile layouts
- Services and illustrative portfolio concepts
- Mobile navigation menu
- Contact form validation
- Copy-inquiry functionality

## Run locally

Open `index.html` in a web browser, or use the Live Server extension in Visual Studio Code.

## Contact form limitation

The contact form is a front-end demonstration. It validates input and allows visitors to copy an inquiry, but it does not send, transmit, or store submissions.

## Portfolio note

Portfolio items are illustrative concepts, not representations of completed client projects.

## Technology

- HTML5
- CSS3
- JavaScript
